# 🤖 Machine Learning Technologies

Machine Learning forms the core intelligence of the OptiCrop system.

| Algorithm                 | Accuracy         | Purpose                     |
| ------------------------- | ---------------- | --------------------------- |
| Random Forest             | 99.86%           | Primary Crop Recommendation |
| Logistic Regression       | 96.36%           | Classification              |
| K-Nearest Neighbors (KNN) | 95.68%           | Similarity-Based Prediction |
