\# 📊 Dataset Information



\## Dataset Name

Crop Recommendation Dataset



\## Source

Kaggle - Atharva Ingle



\## File

`Crop\_recommendation.csv`



\## Description

This dataset contains 2200 samples of soil and environmental parameters for 22 different crops.



\## Features



| Feature | Description | Range |

|:---|:---|:---|

| N | Nitrogen content | 0-140 |

| P | Phosphorous content | 0-145 |

| K | Potassium content | 0-205 |

| temperature | Temperature (°C) | 8-45 |

| humidity | Humidity (%) | 14-100 |

| ph | pH value | 3.5-10 |

| rainfall | Rainfall (mm) | 20-300 |

| label | Crop name | 22 unique |
