## Introduction

Agriculture has increasingly adopted Artificial Intelligence, Machine Learning, and Data Analytics to improve productivity, resource utilization, and decision-making. Various research studies have explored crop recommendation systems, yield prediction models, soil analysis techniques, and smart farming solutions.

This literature survey examines existing research, technologies, and methodologies related to agricultural recommendation systems to identify effective approaches for developing the OptiCrop platform.

---

# 🎯 Objectives of the Literature Survey

* Study existing crop recommendation systems
* Analyze machine learning algorithms used in agriculture
* Understand agricultural data analysis techniques
* Identify challenges and limitations in current systems
* Select suitable methodologies for OptiCrop

---

# 📄 Research Papers Studied

## Paper 1: Crop Yield Prediction using Machine Learning

### Focus

Machine Learning-based crop prediction and yield estimation.

### Key Findings

* Random Forest achieved high prediction accuracy.
* Data preprocessing significantly improved performance.
* Soil and environmental factors strongly influenced predictions.

---

## Paper 2: Smart Agriculture using IoT and Machine Learning

### Focus

Integration of IoT sensors and Machine Learning for smart farming.

### Key Findings

* Real-time environmental monitoring improves recommendations.
* Sensor data enhances prediction reliability.
* Smart farming technologies improve resource efficiency.

---

## Paper 3: Soil Parameter Analysis for Crop Recommendation

### Focus

Analyzing relationships between soil nutrients and crop suitability.

### Key Findings

* Nitrogen, Phosphorous, and Potassium are critical factors.
* Soil quality significantly affects crop productivity.
* Balanced nutrient levels improve agricultural output.
